# TideTracker - Coastal Tide Information

A web application that fetches the user's location and displays tide information for the nearest coast.

## Features

- **Location Detection**: Automatically detects user's location or uses stored location
- **Tide Information**: Displays next high and low tide times with countdowns
- **Tide Timeline**: Visual chart showing tide heights over 24 hours
- **Interactive Map**: Shows user location and nearest coast using Leaflet.js
- **Moon Phase**: Displays current moon phase and illumination
- **Activity Suggestions**: Recommends coastal activities based on tide conditions
- **Favorite Locations**: Save and quickly access favorite coastal locations
- **Responsive Design**: Works on desktop and mobile devices

## Technologies Used

- HTML5, CSS3, JavaScript
- Leaflet.js for maps
- Chart.js for tide visualization
- Moment.js for date/time handling
- Local Storage API for data persistence
